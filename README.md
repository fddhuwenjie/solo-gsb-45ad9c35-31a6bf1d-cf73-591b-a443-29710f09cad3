# 针织行式编译台

用 **Python Flask + 原生 JavaScript/SVG** 实现的针织行式编译台：设置起针数后逐行编写针法，
系统按前一行针数展开当前行并推导下一行针数，源码、展开结果与 SVG 图解三方联动。
支持**针法片段**：在定义区写 `名称 = 针法序列`，各行用 `@名称` 引用，一处修改、处处重算。
支持**逐针来源追溯**：点击展开结果或图解中的某一针，沿各行实际消耗关系逐行找回它
来自哪些针位，直至起针针位或 `yo` 产生的新针。

## 快速启动（单命令）

```bash
docker compose up --build
```

然后访问 **http://localhost:8000**（端口：**8000**，可在 `docker-compose.yml` 的
`ports` 中修改宿主机侧映射）。

### 本地开发（不用 Docker）

```bash
pip install -r requirements.txt
python app.py          # 同样监听 8000 端口 → http://localhost:8000
```

### 运行测试

```bash
python -m unittest -v  # 64 个编译器单元测试，不依赖 Flask
```

## 针法与语法

| 记号    | 含义           | 消耗 | 产出 |
|---------|----------------|------|------|
| `k`     | 下针           | 1    | 1    |
| `p`     | 上针           | 1    | 1    |
| `yo`    | 挂线（空加针） | 0    | 1    |
| `k2tog` | 两针并一针     | 2    | 1    |

- **分组重复**：`(…)xN`，可任意嵌套，如 `(k k, (p, yo)x2, k2tog)x4`。
- **行末重复**：`*…*` 只能出现在整行末尾、不能嵌套。设其内部单次消耗为 `C`、
  当前余针为 `R`：仅当 `C > 0` 且 `R % C == 0` 时，恰好重复 `R / C` 次织到行末；
  否则报错并给出余针数。
- **片段引用**：`@名称`，展开该名称对应的片段（见下节）。
- 分隔符：空白、`,`、`，`、`、`；大小写与全角括号/星号/`@` 均可识别。
- 数字不能直接跟在针法后（`k3` 不合法），重复请写 `(k)x3`。

## 针法片段（定义区 + @引用）

界面上方①为**片段定义区**，每行一条：

```
罗纹   = k k, p p
双罗纹 = @罗纹 @罗纹
镂空   = yo, k2tog
```

行源码中用 `@名称` 引用，可出现在分组与 `*…*` 中：

```
(@罗纹)x6
k k k k, *@镂空*
*@双罗纹*
```

规则：

- 片段可**相互引用**、**前向引用**（先使用后定义），但**不能循环引用**
  （`a → b → a` 会在使用行报错并列出引用链）。
- 片段内**不写行末 `*…*`**（可写分组与 `@引用`）；需要重复到行末时，
  把 `*…*` 写在引用行，如 `*@罗纹*`。
- 分组 `(…)xN` 与行末重复 `*…*` 的次数按片段**实际消耗**计算：
  例如 `镂空 = yo, k2tog` 单次耗 2 针，`k k k k, *@镂空*` 在 10 针上
  先织 4 针、再把 `@镂空` 重复 3 次。
- 修改定义后，所有引用行与后续行**立即重算**。
- **未被引用的片段即使写错也不影响正常行**（定义区行号仅显示为未使用）。
- 缺失引用、循环引用、片段语法错误都**定位到使用它的行与引用位置**，
  并说明所涉定义（错误旁提供「定位定义」按钮跳到定义区对应行列）；
  出错行之后的行按原规则标记「未计算」。

## 编译规则

- 第 1 行消耗「起针数」，之后每行消耗 = 上一行产出。
- 每行消耗必须**恰好**等于可用针数：**不得截断、不得补针**。
- 错误三元组定位：**行号 + 字符列号 + 余针数**，例如
  `第 2 行 · 第 1 列 · '*…*' 单次消耗 3 针，不能整除余针 20（20 % 3 = 2）｜ 余针 20`；
  片段相关错误另附**定义区行列**（`def_line` / `def_col`）与引用链（`chain`）。
- 某行出错后，后续行针数无法推导，标记为「未计算」；修正后自动重算后续所有行。

## 界面联动

- **片段定义**（左上）：`名称 = 针法序列`，行号栏标红错误行、淡化未使用行；
  编辑后 200ms 防抖自动重编译，引用行与后续行立即重算。
- **行源码**（左下）：每行一行针法，可用 `@名称` 引用片段。
- **展开结果**（中）：逐行显示 入→出 针数与展开后的针法序列。来自片段的针法
  以虚线框标记并带 `↗` 按钮：**点击针法定位本次行内引用并选中追溯，点击 ↗
  定位实际针法所在定义**；同一片段的多次引用各自映射回本引用处，互不混淆。
- **SVG 图解**（右）：第 1 行在底部，每格一个产出针（k 竖线 / p 横线 / yo 圆圈 /
  k2tog 斜杠），行右标注产出针数；**单击格元回到行内引用并选中追溯，双击格元
  定位到定义**，悬停显示行号、针位与源码/定义位置。
- 光标在源码中移动时，对应行卡片与图解行号同步高亮。

## 逐针来源追溯

编译响应中每个产出针都携带 `src`：它**实际消耗**的上一行针位（0 基，按上一行
产出顺序编号；第 1 行即起针针位）。`k`/`p` 各承接 1 针，`k2tog` 合并 2 针，
`yo` 没有输入（新针，`src` 为空列表）。分组 `(…)xN`、行末重复 `*…*` 与多次
引用片段都按**每次实际展开**记录针位，不因源码位置相同而合并针目；沿各行
`src` 逐级回溯，即可从任一产出针追到**起针针位**或 **yo 新针**。

界面上，在「展开结果」或「图解」中**单击某一针**即选中并追溯：

- 图解中以**连线标出来源分支**、以**圆点标出起针针位**，来源针与选中针高亮；
- 展开结果中对应针法标记同步高亮；
- 图解下方的追溯面板**逐行文字列出来源针位**；超出图解绘制上限（每行 1000 格）
  而未绘出的针位仍以文字列出，并标注「图中未绘出」；
- 再点同一针、点面板「× 清除」或按 Esc 取消追溯。

追溯随数据即时失效：**编辑源码、定义或起针数会立即清除旧追溯**；出错行与
「未计算」行没有针目、不能选中追溯，修正后按新编译结果重新选择即可。
原有的单击定位行源码、双击定位定义保持可用。

### 操作示例（加针 + 并针 + 片段重复）

定义区写一条含加针与并针的片段：

```
镂空 = yo, k2tog
```

起针 8，行源码：

```
*@镂空*
(k2tog, yo)x4
```

- 第 1 行 `*@镂空*`：`@镂空` 单次耗 2 针（`yo` 加 1 针、`k2tog` 并 1 针），
  8 ÷ 2 = 4，恰好重复 4 次，出 8 针；
- 第 2 行 `(k2tog, yo)x4`：先并后加，入 8 出 8。

在图解第 2 行单击第 1 针（`k2tog`）：它合并第 1 行第 1、2 针；其中第 1 针是
`yo` 新针（支路到此终止），第 2 针 `k2tog` 再向上合并起针第 1、2 针——图解中
可见两条来源分支，一条止于 yo 圆圈，一条连到起针基线上的两个圆点；追溯面板
同步列出「第 1 行：第 1 针（yo 挂线·新针）、第 2 针（k2tog 二并一）」与
「起针针位：第 1 针、第 2 针」。

## 项目结构

```
app.py               Flask 入口（GET / 与 POST /api/compile）
compiler.py          词法/语法/片段解析/展开/逐行推导/逐针来源（纯 Python，可单测）
test_compiler.py     64 个单元测试

Dockerfile           python:3.12-slim + gunicorn（8000 端口）
docker-compose.yml   单服务，映射 8000:8000
```

## API

`POST /api/compile`

```json
{
  "castOn": 24,
  "defs": "罗纹 = k k, p p\n镂空 = yo, k2tog",
  "rows": ["(@罗纹)x6", "k k k k, *@镂空*"]
}
```

- `defs` **可选**（多行字符串或字符串列表）；缺省时按无片段定义编译，
  响应不含 `defs` 键——未使用片段的旧请求与源码定位行为完全不变。

响应中每行包含 `status`（`ok` / `error` / `blocked`）、`in` / `out` 针数、
`stitches`（含源码列区间 `s`/`e`）或 `error`（`row` / `col` / `message` / `remaining`）。
每个针目另含 `src`：它实际消耗的上一行针位（0 基列表；第 1 行即起针针位，
`yo` 为空列表）——即**可机读的逐针前驱关系**，沿各行的 `src` 逐级回溯即可
追到起针针位或 `yo` 新针。
来自片段的针法额外携带 `def`（`line`/`s`/`e`/`name`，实际针法在定义区中的位置）
与 `chain`（引用链）；此时 `s`/`e` 为本次行内 `@名称` 引用的位置。
片段相关错误的 `error` 额外携带 `def_line` / `def_col` / `def_name` / `chain`。
提供 `defs` 时响应另含 `defs.lines`：定义区逐行状态
（`ok` / `unused` / `error`，附 `name`、`used` 与错误位置）。

安全上限：起针 ≤ 2000，行数 ≤ 500，单行 ≤ 2000 字符，分组重复 ≤ 999，
单行展开 ≤ 20000 针，定义区 ≤ 200 行（超出即报错而非耗尽资源）。
